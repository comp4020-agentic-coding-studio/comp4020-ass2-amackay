## set.mm

One text file of axioms, definitions, theorems and proofs, in the
[metamath/set.mm repository](https://github.com/metamath/set.mm).

Its README: "a collection of rigorously verified Metamath databases that
specify mathematical axioms and formal proofs of theorems derived from those
axioms".

[set.mm README](https://github.com/metamath/set.mm/blob/develop/README.md)

```notes
The repository holds several databases; set.mm is the big one and the one
this course works in from here on. The README is the first thing to read when
you clone it.
```

---

## Which mathematics

The README says set.mm "uses classical logic and Zermelo–Fraenkel set theory
with the axiom of choice (ZFC)".

[set.mm README](https://github.com/metamath/set.mm/blob/develop/README.md)

```notes
One foundation, stated in one sentence. Everything in the theorem list on a
later slide is built up from those axioms, and the list is ordered that way.
```

---

## Proofs are stored compressed

The same page says tools "can easily decompress them to provide a
human-readable sequence of every proof step".

[set.mm README](https://github.com/metamath/set.mm/blob/develop/README.md)

```notes
Open the file and a proof is a block of letters, not the list of labels from
week 2. It is the same list, compressed; the Proof Explorer shows you the
decompressed form.
```

## Every change is checked first

"Changes ("commits") to any database are first automatically verified before
they are accepted, using GitHub actions."

[set.mm README](https://github.com/metamath/set.mm/blob/develop/README.md)

```notes
This is last week's workflow, seen from the database's side. Nothing lands in
the file that the five verifiers have not accepted.
```

## The table of contents

The [Theorem List](https://us.metamath.org/mpeuni/mmtheorems.html):

- Part 1: classical first-order logic with equality
- Part 2: Zermelo–Fraenkel set theory
- Part 3: ZFC
- Later parts: real and complex numbers, number theory, algebra, topology

Section 1.2, Propositional calculus, is where Wednesday's lab proves.

```notes
The list is the map of the file. Find section 1.2 before the lab; your
assigned theorem is in it.
```

## Citing books

A theorem's description cites a book by a bracketed label such as [Tarski] or
[Megill]. The home page's
[Bibliography](https://us.metamath.org/mpeuni/mmset.html#bib) expands each
label to a full citation.

```notes
The labels are the database's own citation scheme. When you meet one in a
description, the bibliography section of the home page is where it resolves.
```

---

## The cross-reference

The [Bibliographic Cross-Reference](https://us.metamath.org/mpeuni/mmbiblio.html)
"collects in one place the bibliographic references made in the Metamath Proof
Explorer's axiom, definition, and theorem Descriptions".

```notes
The page says: "If you are studying a particular set theory book, this list can
be handy for finding out where any corresponding Metamath theorems might be
located." The other direction from the bibliography: book first, theorem
second.
```

## Where the history is kept

Old versions of the file live in a separate repository,
[sorear/set.mm-history](https://github.com/sorear/set.mm-history).

Its README: "Each revision corresponds to an archived version of set.mm".

```notes
The same README warns that "you cannot assume old versions of set.mm can be
loaded unmodified in current versions of metamath." An old file is a record,
not something to load and prove in.
```
