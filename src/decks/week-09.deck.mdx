## GCH implies AC

Mario Carneiro, [CICM 2015](http://www.cicm-conference.org/2015/).

metamath.org's [other topics page](https://us.metamath.org/other.html) links
the video, slides and [paper](https://doi.org/10.48550/arxiv.1506.03533).

```notes
GCH is the generalised continuum hypothesis, AC the axiom of choice. The
paper formalises Specker's "local" version of the claim.
```

## Legibility as a research question

[Lindsay, Kaliszyk and Rizkallah (2026)](https://doi.org/10.48550/arxiv.2609.07097):
Metamath's "verification architecture prioritises algorithmic efficiency over
human readability."

Reordering inferences can cut a reader's working memory load without changing
proof size.

```notes
From the abstract as OpenAlex records it. The verifier does not care in what
order the steps come; a reader does. Wednesday's plan is about the order.
```

## Granularity

[Oliveira and Pimentel (2021)](https://doi.org/10.1109/laclo54177.2021.00051)
propose adapting the level of detail at which a proof is shown, using
Metamath's step-level structure.

```notes
The second paper on the same theme: the proof is stored at every step, so a
presentation can choose how many of them to show.
```

## Before Wednesday's lab

1. Choose a target too big for one worksheet: Teodor has a list, or ask
   today
2. Write the plan before opening mmj2: target, then lemmas, each a Metamath
   statement, in order
3. How set.mm does it: `pnt` with `pnt2` and `pnt3` beside it

```notes
A lemma is a statement, not a paragraph: each with its hypotheses and the
set.mm theorems you expect it to lean on. Teodor reads every plan in the first
twenty minutes, and a lemma that quietly assumes the target is rewritten
before anything is proved.
```

---

## What the lab checks

- The plan is checked before you type a proof
- Each lemma and the final proof verify in mmj2
- The file passes `verify proof *` in metamath.exe
- You can say which axioms the target depends on

```notes
The last one is a metamath.exe command, show trace_back, given on the Proof
Explorer home page. The plan is submitted with its changes; a lemma that
changed, with a line on why, counts for it.
```
