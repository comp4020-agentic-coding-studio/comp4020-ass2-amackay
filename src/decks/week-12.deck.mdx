## Metamath Solitaire

A Java applet: [mmsolitaire.zip](https://us.metamath.org/downloads/mmsolitaire.zip),
from the [home page](https://us.metamath.org/index.html).

Megill, in Wiedijk's survey: "a unification algorithm lets the user know
exactly what possibilities are available at any point in a proof", and it "is
not practical for larger proofs"
([PDF, p. 104](https://www.cs.ru.nl/~freek/comparison/comparison.pdf)).

```notes
Its author's own assessment, in a survey of seventeen provers. Think of it as
mmj2's unification step with the rest of the assistant removed.
```

## The shortest Principia proofs

[pmproofs.txt](https://us.metamath.org/mmsolitaire/pmproofs.txt) holds proofs
of "all 193 theorems of propositional calculus" in Principia Mathematica.

- From ax-1, ax-2, ax-3 and ax-mp
- In a notation the file calls condensed detachment

```notes
You read this file's header for last Wednesday's lab and checked one of its
proofs by hand. Today is the file as an artefact: who shortened what, and
when.
```

---

## Twenty-one years of shortening

The file's revision history runs from Gregory Bush's 2004 shortening of 67
proofs to Samiro Discher's 2025 shortening of 38 with pmGenerator.

[pmproofs.txt](https://us.metamath.org/mmsolitaire/pmproofs.txt)

```notes
The history is in the file itself, with names and programs. A proof in it is
only the shortest known, and the file says so each time one falls.
```

## History, as far as it is documented

The [set.mm README](https://github.com/metamath/set.mm/blob/develop/README.md)
dedicates the collection to the memory of Norman "Norm" Dwight Megill, Ph.D.
(1950-2021), "creator of the Metamath system and cultivator of an international
community of people with the shared dream of digitizing and formally verifying
mathematics".

That is what is documented.

```notes
One slide, one source. Anything more about the project's early years would
be recollection, and this course does not teach from recollection.
```
