## Two words for the whole course

- A **database** is a text file: axioms, theorems, proofs.
- A **verifier** is a program that checks every proof in it.

Both in the project's words:
[Mini FAQ, "What is Metamath?"](https://us.metamath.org/index.html)

```notes
The FAQ calls a database "a collection of axioms (assumptions), theorems, and
proofs", and says verifiers "verify that a database is correct". On Wednesday
you run one over the biggest database there is.
```

## The name

It means "metavariable math", and is not _metamathematics_, the branch of
mathematics that studies mathematics itself.

The name has been in public use since 1994.

[Mini FAQ, "Why is it called Metamath?"](https://us.metamath.org/index.html) ·
[Copyright Terms](https://us.metamath.org/copyright.html)

```notes
Search results mix the two constantly. The 1994 date sits on the copyright
page, under Trademarks, of all places.
```

## Where it lives

- `us.metamath.org` — primary mirror, United States
- `cn.metamath.org` — secondary mirror, China

Permanent links use `us.metamath.org`. So does your work.

[Metamath Site Selection](https://us.metamath.org/mm.html)

```notes
Two mirrors, one preferred for links. When you cite a page in a lab report or
the project report, that is the hostname.
```

---

## How a mirror stays in step

```sh
rsync -vrltS -z --delete --delete-after \
    rsync://rsync.metamath.org/metamath $DIR
```

Run as a nightly cron job, pulling from the primary. The whole recipe is one text
file: [mirror.txt](https://us.metamath.org/mirror.txt)

```notes
The site is static files copied by rsync. That is why an off-line copy is
possible, and why a mirror can be a day behind.
```

## The licence

- Databases: public domain, under CC0
- The exception: `peano.mm`, under the GNU GPL
- Software on the site: GPL version 2 or later, unless a file says otherwise

[Copyright Terms](https://us.metamath.org/copyright.html)

```notes
This is what you may do with Wednesday's downloads. Contributors are asked to
put database work in the public domain too, and the page says why.
```

## A second description

Wikipedia: "a formal language and an associated computer program (a proof
assistant) for archiving and verifying mathematical proofs".

It counts at least 19 verifiers for the format.

[Metamath on Wikipedia](https://en.wikipedia.org/wiki/Metamath)

```notes
Written by outsiders, so a different emphasis: the program first, the language
second. Week 3 comes back to that count of verifiers.
```

## Five verifiers, five languages

The Proof Explorer "is routinely checked by 5 independently-created verifiers
in 5 different programming languages".

Yours will be one more.

[Mini FAQ, "How confident can I be in the proofs?"](https://us.metamath.org/index.html)

```notes
This is the argument for the project. The language is small enough that
independent implementations are normal, and disagreement between them is the
check.
```

## The other Metamaths

- 2023: a language-model paper, dataset MetaMathQA —
  [arXiv](https://doi.org/10.48550/arxiv.2309.12284),
  [OpenAlex](https://openalex.org/W4386978002)
- 2014: a Russian-language article on a Tempus-programme project in maths
  education — [OpenAlex](https://openalex.org/W2955268382)
- 2026: a paper on assessing mathematical metacognition in primary school —
  [OpenAlex](https://openalex.org/W7160684602)

```notes
The 2023 one is the one you will hit most: "MetaMath" with a capital M in a
machine-learning context is almost always it.
```
